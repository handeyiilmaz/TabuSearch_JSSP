## Requirements
- Python 3.8 or higher
- No external libraries needed

## How to Run

Test on example instance:
```bash
python3 tabu_search.py
```

Run full experiments (all 30 instances x 5 seeds):
```bash
python3 run_experiments.py
```

## Notes
- Place all benchmark `.txt` files inside the `instances/` folder
- Results are saved automatically to `results.txt`
- Runtime: approximately 5-10 minutes for full experiments
